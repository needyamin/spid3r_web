Spid3rWeb

A lightweight MVC framework powered by the Spid3r language.

Next steps

  1. 1
    Edit this page resources/views/welcome.bd.html
  2. 2
    Add routes routes/web.matrix — register pages with Route.get / Route.post
  3. 3
    Create models & controllers spid3r magic make:model Post
    spid3r magic make:controller PostController
  4. 4
    Run migrations spid3r magic migrate
  5. 5
    Run the test suite spid3r magic test

Useful locations in this project:

  • app/ — controllers, models, middleware
  • resources/views/ — SpiderBD templates
  • routes/ — web, api and queue job registrations
  • config/ — app, auth, session, mail, queue, logging, filesystems, services
  • database/migrations/ — schema migrations
  • developer-docs.html — full framework documentation
